# Resta — операционный playbook (Head of Growth)

Практическая реализация утверждённой стратегии [`../GROWTH_STRATEGY.md`](../GROWTH_STRATEGY.md) (v3). При противоречии стратегический документ считается базой, но операционное решение принимается по playbook, если оно уточняет стратегию — playbook живёт и обновляется чаще.

| Файл | Что внутри |
|---|---|
| [`01-OPERATIONS.md`](01-OPERATIONS.md) | Посуточный план на 30 дней · структура CRM в Google Sheets (5 листов: рестораны, работники, ядро, школы, чаты) · Telegram-экосистема (канал, приватная группа ядра, боты) · 8 готовых скриптов сообщений с follow-up и правилами «когда перестать писать» · чек-лист «смена горит» |
| [`02-CREATIVE.md`](02-CREATIVE.md) | 33 концепции баннеров по 5 блокам (работники / шеринг / управляющие / презентации / ритуалы) с заголовками, композицией, цветами и психологией · контент-план канала на 60 дней (~85 постов, 18 полных образцов текстов, 3 фазы: сводка рынка → подмешивание своих смен → свои смены как ядро) |
| [`03-EXPERIMENTS.md`](03-EXPERIMENTS.md) | Живая система управления ростом: дашборд Active Experiments (обновляется еженедельно) · kill-правила · 102 эксперимента по 9 стадиям воронки со Status (с честной маркировкой, где A/B невозможен) · 20 growth-экспериментов дистрибуции · 13 growth-функций с MVP за неделю · 3 Growth Loops со схемами и точками разрыва · ICE-приоритизация 34 позиций + Expected Impact · «Чего НЕ делаем» до 50 ресторанов / 500 работников / 500 смен |
| [`04-CONTENT-60-DAYS.md`](04-CONTENT-60-DAYS.md) | 114 готовых к публикации текстов постов на 60 дней (копипаст в Telegram): фаза 1 — сводка рынка (дни 1–19), фаза 2 — подмешивание своих смен 🔴 (20–40), фаза 3 — свои смены как ядро (41–60); подстановки только в [скобках], у каждого поста — номер баннера из 02-CREATIVE и CTA |

Общие ограничения во всех документах: бюджет ≈ 0, без рекламы/блогеров/таргета; обещание всегда мягкое («попробуем найти замену быстро и бесплатно»); санкции за невыход ступенчатые; в канале-сводке — пересказ + ссылка на источник, без копирования текстов и личных данных; слово «регистрация» пользователям не показывается.
