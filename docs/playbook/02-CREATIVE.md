# Resta · Playbook 02 — Креативы и контент-план канала

**Источник истины:** [`docs/GROWTH_STRATEGY.md`](../GROWTH_STRATEGY.md). Этот документ — исполнение, не пересмотр стратегии.

**Жёсткие рамки (из стратегии, повторяем, чтобы не забыть при производстве):**

- Бюджет ≈ 0. Всё делается в Canva/Figma бесплатно; фото — из заведений с разрешения или свои скриншоты приложения.
- Никакой платной рекламы, блогеров, таргета.
- Обещания только мягкие: **«попробуем найти замену быстро и бесплатно»**. Никаких «за 2 часа», пока нет статистики по 30+ закрытым сменам.
- То же для любых фактических утверждений в креативах («ставка выше», «разбирают за N минут», «уходят первыми»): используем только то, что подтверждено нашими данными; без данных — мягкие формулировки («часто», «бывает»).
- Слово «регистрация» пользователям не показываем. Формулировки: «жми — откликнись», «открой смену», «аккаунт создастся сам».
- Чужие вакансии — только пересказ своими словами + ссылка на источник. Без копирования текста, без телефонов и имён контактных лиц.
- Свои смены помечаются 🔴 и ведут по deep link `https://t.me/<bot>/<app>?startapp=shift_<id>` (формат для Mini App, открывающегося через bot/app; сверить с реальной настройкой бота — если приложение открывается напрямую с бота, ссылка без `/<app>`).
- В продукте **есть**: лента смен, отклик, метка «срочная» (urgent), отзывы/рейтинги, уведомления. **Пока нет** (можно писать только «скоро»): автопостинг-бот, кнопка «передать смену».
- Монетизация выключена до месяца 7 — в креативах ни слова о платных функциях.

## Раздел 1. Концепции баннеров и визуалов (33 шт.)

**Общие правила производства.**

- Формат постов канала: 1280×720 или квадрат 1080×1080. Карточки шеринга: 1080×1350 (лучше видно в пересылке). Слайды презентаций: 16:9.
- Telegram-палитра: баннеры смотрятся и в light-, и в dark-теме клиента. Базовое правило: **тёмный фон (#17212B / #1F2A36) + белый текст + один акцент**. Акценты: красный `#E53935` — только для срочного 🔴; тёплый жёлтый `#FFC93C` — деньги/ставка; зелёный `#4CAF50` — «закрыто/успех». Не использовать чисто белый фон (сливается в light-теме с фоном чата — нужна рамка или подложка).
- Шрифты: один жирный гротеск (Inter/Manrope, есть в Canva бесплатно). Цифры — крупнее слов.
- Ни одного стокового «официанта с подносом и улыбкой». Только: реальные фото из заведений (с разрешения), скриншоты приложения, типографика и цифры.

Формат описания: **№ · Цель · Аудитория · Заголовок · Подзаголовок · CTA · Композиция · Что изображено · Цвета · Почему сработает.**

### Блок А. Работники — привлечение (верх воронки)

**1. «Смена завтра — деньги на неделе»**
- **Цель:** первый контакт из рабочих чатов; главный баннер пересылок.
- **Аудитория:** работник (официанты, бармены, повара).
- **Заголовок:** «Смена завтра. Без собеседований.»
- **Подзаголовок:** «Открыл → откликнулся → вышел. Всё в Telegram.»
- **CTA:** «Смотреть смены →»
- **Композиция:** три слова-шага по вертикали, стрелки между ними, CTA-плашка внизу.
- **Что изображено:** чистая типографика + маленький скриншот карточки смены из приложения в углу.
- **Цвета:** тёмный фон #17212B, шаги белым, CTA жёлтым #FFC93C.
- **Почему сработает:** «деньги сегодня/на этой неделе» + снятие барьера (нет собеседования, нет резюме). Минимум обещаний — только механика.

**2. Карточка срочной смены 🔴 (шаблон)**
- **Цель:** рабочий шаблон для каждого поста со своей сменой.
- **Аудитория:** работник.
- **Заголовок:** «🔴 СРОЧНО · [позиция]» (напр. «🔴 СРОЧНО · Бармен»)
- **Подзаголовок:** «[район/улица] · [дата] · [часы] · [ставка] BYN/ч»
- **CTA:** «Откликнуться →» (кнопка-ссылка `startapp=shift_<id>`)
- **Композиция:** красная вертикальная полоса слева (как метка в чате), данные смены крупно построчно, ставка — самым большим кеглем.
- **Что изображено:** только данные. Без фото — скорость чтения важнее красоты. Один шаблон, меняются поля.
- **Цвета:** фон #1F2A36, полоса и «СРОЧНО» — #E53935, ставка — #FFC93C.
- **Почему сработает:** срочность + конкретная сумма. Человек решает за 3 секунды: «моя позиция, мой район, моя ставка».

**3. Карточка обычной своей смены (шаблон, без 🔴)**
- **Цель:** шаблон несрочных своих смен, чтобы 🔴 не девальвировалось.
- **Аудитория:** работник.
- **Заголовок:** «[позиция] · [заведение или район]»
- **Подзаголовок:** «[дата] · [часы] · [ставка] BYN/ч»
- **CTA:** «Открыть смену →»
- **Композиция:** тот же макет, что №2, но полоса слева синяя, без слова «срочно».
- **Что изображено:** данные смены.
- **Цвета:** фон #1F2A36, полоса #4EA4F5 (телеграмный синий), ставка #FFC93C.
- **Почему сработает:** визуальная система «красное = горит, синее = обычная» приучает канал читать глазами за секунду; 🔴 сохраняет силу.

**4. «Без резюме. Без „расскажите о себе“»**
- **Цель:** снять барьер входа у линейного персонала.
- **Аудитория:** работник (особенно молодые, студенты).
- **Заголовок:** «Резюме не нужно.»
- **Подзаголовок:** «Ты либо умеешь стоять смену, либо нет. Тут это понимают.»
- **CTA:** «Найти смену →»
- **Заголовок/композиция:** перечёркнутый лист «резюме» (простая иконка) слева, текст справа.
- **Что изображено:** иконка документа с красным крестом, типографика.
- **Цвета:** тёмный фон, крест #E53935, текст белый.
- **Почему сработает:** принадлежность к цеху («тут понимают») + снятие страха формальностей — главного барьера для линейного персонала.

**5. «Подработка рядом с домом» — карта районов**
- **Цель:** показать, что смены есть по всему городу, не только в центре.
- **Аудитория:** работник из спальников.
- **Заголовок:** «Смены не только в центре.»
- **Подзаголовок:** «Уручье, Малиновка, Каменная Горка — смотри, что рядом.»
- **CTA:** «Смены рядом →»
- **Композиция:** упрощённый контур Минска (нарисовать вручную в Figma), точки-маркеры по районам.
- **Что изображено:** схематичная карта с точками, у 2–3 точек — подписи со ставкой.
- **Цвета:** фон тёмный, контур серым #6B7A8D, точки жёлтые, одна красная (🔴 срочная).
- **Почему сработает:** «рядом с домом» — экономия часа дороги, личная релевантность. Карта = визуальное соцдоказательство охвата.

**6. «Ночные — для тех, кто живёт после 23:00»**
- **Цель:** сегмент барменов/барбэков ночных заведений.
- **Аудитория:** работник (бар-сегмент).
- **Заголовок:** «Ночная смена. Бар.»
- **Подзаголовок:** «18:00–02:00. Ночные смены часто разбирают быстрее.» (Формулировки «ставка выше дневной» / «уходят первыми» — только когда это подтверждено нашими данными; без данных не утверждаем.)
- **CTA:** «Ловить смены →»
- **Композиция:** почти чёрный фон, неоновый тонкий контур бокала, текст крупно.
- **Что изображено:** минималистичная неоновая линия-иллюстрация (рисуется пером в Figma за 10 минут).
- **Цвета:** фон #0E1621, неон #FFC93C или #E53935, текст белый.
- **Почему сработает:** «часто разбирают быстрее» — дефицит + причина включить уведомления, при этом без проверяемого обещания. Эстетика «своих» для ночного цеха.

**7. «Уведомления: узнаёшь первым»**
- **Цель:** активация — включить уведомления в приложении (реальная функция).
- **Аудитория:** работник, уже открывший приложение.
- **Заголовок:** «Хорошие смены разбирают за час.»
- **Подзаголовок:** «Включи уведомления — узнаешь раньше остальных.»
- **CTA:** «Включить в приложении →»
- **Композиция:** скриншот push-уведомления (замокапить на рамке телефона), под ним текст.
- **Что изображено:** мокап уведомления «🔴 Срочная смена: бармен, Октябрьская, 15 BYN/ч».
- **Цвета:** рамка телефона тёмная, уведомление в системном стиле, акцент красный.
- **Почему сработает:** страх упустить (смены — скоропортящийся товар) переводится в конкретное действие.

**8. «Твой рейтинг — твои смены»**
- **Цель:** удержание, объяснение системы отзывов/рейтингов (реальная функция).
- **Аудитория:** работник с 1+ сменой.
- **Заголовок:** «Вышел вовремя → отзыв → рейтинг растёт.»
- **Подзаголовок:** «Работников с высоким рейтингом зовут первыми.»
- **CTA:** «Проверить свой рейтинг →»
- **Композиция:** скриншот блока отзывов/звёзд из приложения, стрелка вверх.
- **Что изображено:** реальный (или демо) профиль с рейтингом, размытое имя.
- **Цвета:** тёмный фон, звёзды жёлтые, стрелка зелёная #4CAF50.
- **Почему сработает:** репутация в цеху — валюта. Показывает, что надёжность конвертируется в деньги, и заранее работает против невыходов.

### Блок Б. Работники — контент и шеринг (середина воронки)

**9. Зарплатная карта: «Сколько платят бармену в Минске»**
- **Цель:** виральный пересылаемый контент; канал = источник данных о рынке.
- **Аудитория:** работник + управляющий (пересылают обе стороны).
- **Заголовок:** «Бармен в Минске: центр vs спальник»
- **Подзаголовок:** «Наши наблюдения по открытым вакансиям за [месяц]» (только честная формулировка «по открытым источникам», пока нет своих данных).
- **CTA:** «Больше цифр — в канале @…»
- **Композиция:** две больших цифры рядом («X–Y BYN/ч» / «X–Y BYN/ч»), подписи под ними, мелкий дисклеймер про источник.
- **Что изображено:** цифры, ничего лишнего.
- **Цвета:** тёмный фон, цифры жёлтым, подписи серым.
- **Почему сработает:** деньги + любопытство «а мне недоплачивают?». Такое пересылают в рабочие чаты сами — бесплатный охват.

**10. «Цифра недели» (шаблон)**
- **Цель:** регулярная рубрика, ритм канала.
- **Аудитория:** работник, управляющий.
- **Заголовок:** одна цифра во весь баннер (напр. «14 BYN/ч»)
- **Подзаголовок:** «средняя ставка официанта по открытым вакансиям Минска на этой неделе»
- **CTA:** «Следить за рынком →»
- **Композиция:** цифра занимает 60% площади, подпись снизу.
- **Что изображено:** типографика.
- **Цвета:** тёмный фон, цифра жёлтым.
- **Почему сработает:** одна цифра читается из ленты без открытия поста; регулярность создаёт привычку возвращаться.

**11. Опрос-подложка «А сколько у тебя?»**
- **Цель:** вовлечение + сбор собственных данных о ставках.
- **Аудитория:** работник.
- **Заголовок:** «Сколько выходит за смену у тебя?»
- **Подзаголовок:** «Анонимный опрос ниже 👇 Итоги — через неделю.»
- **CTA:** — (CTA — сам телеграм-опрос под баннером).
- **Композиция:** вопрос крупно, стрелка вниз к опросу.
- **Что изображено:** типографика + знак вопроса.
- **Цвета:** тёмный фон, вопрос белым, стрелка жёлтым.
- **Почему сработает:** про деньги отвечают охотно, если анонимно; итоги опроса = следующий пост = собственные данные вместо чужих.

**12. Тизер «Передай смену» (СКОРО)**
- **Цель:** прогрев главной будущей механики; сбор ожидания.
- **Аудитория:** работник.
- **Заголовок:** «Не можешь выйти — сам ищешь замену. Знакомо?»
- **Подзаголовок:** «Скоро: кнопка „передать смену“ — переслал коллеге, он принял, все спокойны.»
- **CTA:** «Ждём вместе → @канал»
- **Композиция:** две иконки-аватара, между ними стрелка с карточкой смены.
- **Что изображено:** схема передачи (простые круги-аватары, стрелка).
- **Цвета:** тёмный фон, стрелка зелёная, плашка «СКОРО» жёлтая.
- **Почему сработает:** описывает реальное цеховое правило («сам ищешь замену») — узнавание. Честная плашка «скоро» не выдумывает функцию.

**13. Шеринг-карточка смены (для пересылки коллеге)**
- **Цель:** визуал, который не стыдно переслать лично человеку («глянь, тебе подходит»).
- **Аудитория:** работник → работник.
- **Заголовок:** «Тебе подойдёт 👇»
- **Подзаголовок:** данные смены (позиция · район · дата · часы · ставка).
- **CTA:** «Открыть смену →» (`startapp=shift_<id>`)
- **Композиция:** вертикальная 1080×1350, смена как «билет» с перфорацией по краю.
- **Что изображено:** карточка-«билет», внизу мелко логотип.
- **Цвета:** светлая карточка #F5F5F0 на тёмной подложке (видно в обеих темах), акценты красный/жёлтый.
- **Почему сработает:** личная пересылка от знакомого = самая высокая конверсия; формат «билета» намекает «место одно, займи».

**14. «Мы из цеха» — манифест**
- **Цель:** идентичность канала; закреп и «о нас».
- **Аудитория:** работник.
- **Заголовок:** «Сделано людьми, которые сами стояли смены.»
- **Подзаголовок:** «Без HR-словаря. Без „динамично развивающихся команд“. Смена, ставка, адрес.»
- **CTA:** «Это наш канал →»
- **Композиция:** текст как маркировка на кухонном тикете/чеке (моноширинная вёрстка чека).
- **Что изображено:** стилизация под кухонный чек заказа.
- **Цвета:** «чек» светлый на тёмном фоне, текст чёрный, штамп красный.
- **Почему сработает:** принадлежность к цеху и анти-корпоративность — прямое отличие от джоб-бордов. «Свои» узнают эстетику тикета мгновенно.

**15. Баннер для выпускников школ (бармены/бариста/официанты)**
- **Цель:** партнёрский визуал для рассылки школами своим выпускникам.
- **Аудитория:** школа → её выпускники.
- **Заголовок:** «Курс закончил. Где первая смена?»
- **Подзаголовок:** «Разовые смены в заведениях Минска — способ набрать практику и первые отзывы.»
- **CTA:** «Смотреть смены →»
- **Композиция:** слева «диплом/сертификат» (иконка), справа карточка смены, между ними стрелка.
- **Что изображено:** иконки + мини-скриншот ленты смен.
- **Цвета:** тёмный фон, стрелка зелёная; место под логотип школы (ко-брендинг) в углу.
- **Почему сработает:** решает главную боль выпускника — «нет опыта, никуда не берут»: разовая смена = вход без опыта; рейтинг и отзывы = накопление репутации. Школе даёт аргумент «наши выпускники находят работу».

**16. Ко-бренд со школой (шаблон партнёрства)**
- **Цель:** визуал для поста в канале школы о партнёрстве.
- **Аудитория:** школа (админ) + её аудитория.
- **Заголовок:** «[Школа X] × Resta»
- **Подзаголовок:** «Выпускники курса получают доступ к ленте смен минских заведений.»
- **CTA:** «Подробнее у администратора школы»
- **Композиция:** два логотипа через ×, под ними одна строка сути.
- **Что изображено:** логотипы, нейтральный фон.
- **Цвета:** тёмный фон, логотипы в белых плашках (чтобы любые логотипы читались).
- **Почему сработает:** школе — статус («у нас партнёрство»), нам — доверенный канал. Официальный вид повышает ценность для обеих сторон.

### Блок В. Управляющие и администраторы (спрос)

**17. «Пятница, 17:40» — сценарий страха**
- **Цель:** первый эмоциональный контакт с управляющим/админом.
- **Аудитория:** администратор, управляющий.
- **Заголовок:** «Пятница. 17:40. „Я сегодня не приду.“»
- **Подзаголовок:** «Знакомое сообщение? Разместите смену — попробуем найти замену быстро и бесплатно.»
- **CTA:** «Разместить смену →»
- **Композиция:** мокап телеграм-сообщения от «Саша (бармен)» с этим текстом, снизу ответ-решение.
- **Что изображено:** пузырь чата (без реальных имён/фото — вымышленное имя, серый аватар).
- **Цвета:** интерфейс чата в дарк-теме, ответная плашка зелёная.
- **Почему сработает:** страх невыхода — самая горячая боль; мокап чата вызывает мгновенное узнавание. Обещание мягкое, ровно по стратегии.

**Правила публикации (из стратегии):**

### 2.3 Операционные заметки

- **Гибкость слотов:** план — расписание слотов, не обещание контента. Реальная 🔴 смена всегда вытесняет любой запланированный пост своего окна; выдуманная смена не публикуется никогда.
- **Кейсы (Г1/Г2) публикуются только по реальным событиям** и после согласия участников; имена меняем, заведение называем только с разрешения.
- **Единый тон:** работникам — «ты», цеховой язык, без канцелярита; управляющим — «вы», спокойно, без давления. Обещание всегда одно: «попробуем найти замену быстро и бесплатно».
- **Каждый пост со своей сменой** несёт кнопку `startapp=shift_<id>`; посты про приложение без конкретной смены ведут на общий deep link Mini App.
- **Производство баннеров:** за первую неделю собрать в Canva/Figma мастер-шаблоны №2, №3, №10, №22, №23 (они повторяются чаще всего) — дальше только подстановка полей, 5 минут на пост.
